# Architecture Decision Records

Accepted decisions for Eollo. ADRs record *why* a decision was made; specs record how it is
implemented.

| ADR | Decision |
|---|---|
| [0001](0001-eollo-capability-runtime.md) | Eollo is a composable multi-domain capability runtime. |
| [0002](0002-ethereum-bsc-chain-matrix.md) | Ethereum and BSC are declared, first-class chains. |
| [0003](0003-capability-envelope-v2.md) | Every capability uses envelope v2. |
| [0004](0004-composable-workflows.md) | Workflows are first-class compositions. |
| [0005](0005-capability-catalog.md) | The capability catalog is the single source of truth. |
| [0006](0006-rename-to-eollo.md) | The product, CLI, crates, and domain are renamed to Eollo. |

See [CONTEXT.md](../../CONTEXT.md) for terminology.
