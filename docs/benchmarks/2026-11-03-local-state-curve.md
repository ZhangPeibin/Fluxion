# #33：经典 Curve 3pool 本地精算（2026-11-03）

本切片只实现具体的 DAI/USDC/USDT 3pool。默认 Curve 发现仍有 5 个部署，其他 4 个保留为
明确未支持。本记录不代表全平台 90 行迁移或默认模式切换。支持矩阵及公式边界见
[CURVE-SUPPORT](../CURVE-SUPPORT.md)。

## 清点与离线原始向量

- [清点 JSON](2026-11-03-curve-inventory.json)：区块 26331147、注册表 [0,5]、默认 all-token
  allowlist，共 5 个池，block hash 校验通过，322 RPC 尝试。并未改变发现/过滤规则。
- `tests/fixtures/curve-3pool-20000000.json`：A=2000、fee=1000000。
- `tests/fixtures/curve-3pool-26331147.json`：A=4000、fee=1500000。
- 每个 fixture 为 32 个直接从部署 get_dy 捕获的 raw 向量，共 **64/64** 本地整数相等。
  包括六方向、1e6 raw、单位量、单位量+1、1000/10000/100000 整币，不用本地公式生成期望值。
- 离线 HTTP mock 仅回放原始值，不在 mock 内调用生产数学。关闭 RPC 后仍可完成全部币向；
  新旧历史参数替换时，旧快照不变。缺失余额、币序错误、probe 不符不部分发布。
