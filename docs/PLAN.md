# Fluxion 教学版里程碑（PLAN）

> 目标：不只是交付服务，而是带你**掌握** DEX 路由询价的原理与实现。
> 学习节奏：稳扎稳打 —— 每阶段「先讲原理 → 一起设计 → 实现 → 复述/检查点 → 小实验验证」。

## 学习方式

每个阶段按循环推进，而不是我默默写完：

1. **先讲原理**：这块是什么、为什么这么设计、有哪些坑（类比 + 简化例子）。
2. **一起设计**：关键决策（数据模型、算法）先让你选，你理解了再拍板。
3. **我实现，你审**：写代码时解释每个关键点。
4. **检查点**：每阶段结束我出题，你答上来才算过；答不上就回炉重讲。
5. **小实验验证**：跑起来看真实数字，让抽象概念落地。

每阶段产出 `docs/0X-阶段名.md` 学习笔记（原理 + 关键代码解读 + 你的要点）。

## 你的底子（校准用）

- Rust：写过小项目、语法学过但忘了 → 加 P0 热身，逐阶段顺带复习。
- DEX/AMM：懂 → 原理不啰嗦，直接讲实现细节。
- 图算法：生疏 → P5 前专项讲透，是本项目学习重点。
- 节奏：稳扎稳打。

## 里程碑

| 阶段 | 交付 | 学习目标 | 检查点（过了才前进） |
|---|---|---|---|
| **P0 Rust 热身** | 最小异步 demo（就用项目代码） | 所有权/借用、`trait`、`Result`+`?`、`async/await`+tokio、Cargo | 能解释一段 `async trait` 实现为何要 `Box<dyn>` |
| **P1 模型+多重图** | Token/Pool/Edge/Route、多重图 | struct/enum/Vec/HashMap；为何自定义邻接表；平行边；多币池有序对展开 | 手推 3pool 生成 6 条边 |
| **P2 发现+过滤** | subgraph/registry 预载、过滤、落盘 | subgraph 分页、token 白名单、阈值过滤逻辑 | 说明无交易池为何「降级不剔除」 |
| **P3 适配器** | V2/V3/Curve 真实 quote | V2 常数积推导、V3 fee+Quoter、Curve 池类型分派 | 手算一笔 V2 `amountOut` |
| **P4 刷新缓存** | 热池 multicall + 懒加载 | Multicall3 原理、热/冷池、TTL、RPC 限流 | 说明为何不全量刷新 |
| **P5 路由（重点）** | K-best DP + 简单路径 + 精算 | 为何 `-ln(rate)` 有负权→弃 Dijkstra、Bellman-Ford、K-best DP、简单路径、流动性惩罚 | 白板推一遍 Bellman-Ford 松弛过程 |
| **P6 服务** | axum `/quote` + 错误+限流 | axum handler、状态共享、错误→HTTP 映射 | 讲清一次请求的完整数据流 |
| **P7 测试观测** | mock 单测 + 主网 RPC 测试 + 固定区块 fixture + tracing | 测试策略、主网 RPC 只读测试、fixture 确定性、日志 | 写一个漏路径的反例测试 |

## 核心概念清单（逐个讲透）

- AMM 基础：V2 常数积 `x*y=k`、V3 集中流动性、Curve StableSwap
- 图建模：多重图、平行边、多币池展开
- 路由：mid-price vs 精确报价、最短路径 vs K-best DP、滑点/价格冲击
- 工程：subgraph、multicall、eth_call/Quoter、缓存策略
