# Brand assets

Marketing and social assets for the Eollo X account. Nothing here is imported by the site or any
build; these are source files and rendered exports kept with the project.

## Palette

| Role | Hex |
| --- | --- |
| Ink (background) | `#0C0E11` |
| Paper (foreground) | `#F2EFE6` |
| Accent | `#FF6A2B` |
| Muted text | `#8E949D` |

## Files

`x/` — project account:

- `eollo-avatar-400.png`, `eollo-avatar-512.png` — profile image exports of the keyhole mark.
- `concept-a/b/c.svg` and `.png` — mark explorations: keyhole, routing node, routed E.
- `banner-a.svg`, `banner-c.svg` and `.png` — 1500×500 profile banners using the keyhole and routed E
  marks. Both carry the tagline “Agents get hands. You keep the keys.”

`x/personal/` — personal-account profile sets. Each set has a 256×256 avatar and a 1500×500 banner:

- `p1-dusk` — dusk gradient.
- `p2-loading` — loading indicator.
- `p3-bauhaus` — geometric Bauhaus composition.

## Conventions

- SVG is the editable source; PNG files are rendered exports at the stated display size.
- Keep new files inside `brand/x/` or `brand/x/personal/` so the exports stay together.
- Banners are 1500×500 and avatars are 400 or 512 px square, matching X's current upload sizes.
